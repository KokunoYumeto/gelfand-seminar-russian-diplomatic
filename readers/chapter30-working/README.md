# Gelfand seminar: separate Russian and English A4 readers, chapter 30

This working release contains **all 26 held source frames of chapter 30**, GELFAND-P001359–GELFAND-P001384, as two separate flowing readers: **45 pages in Russian** and **43 pages in English**. Text, formulas, cancellations, written diagram labels and uncertain readings are typeset in LaTeX. Each reader retains all 109 historical uncertainty records in a linked appendix, plus two additional diagram observations.
