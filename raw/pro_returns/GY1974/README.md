# GY1974 — Critical companion to the 1974–75 Gelfand seminar records

Start with **GY1974_test.pdf**, the complete 143-page chapter, or
**GY1974_report.md**, the research and methodology report with APA-style
references. The chapter preserves the distinction between the notebook,
modern mathematical statement, editorial reconstruction and subsequent
literature. Status statements are dated **November 2026**.

## Rebuild the PDF

From this directory, with Python 3 and a complete XeLaTeX/BibTeX installation:

    python3 build_chapter.py GY1974
    xelatex -interaction=nonstopmode -halt-on-error GY1974_test.tex
    bibtex GY1974_test
    xelatex -interaction=nonstopmode -halt-on-error GY1974_test.tex
    xelatex -interaction=nonstopmode -halt-on-error GY1974_test.tex

See **code/README.md** for dependencies, regeneration from the preserved
editorial snapshots, mathematical checks, and the optional environment helper.
The default regeneration needs no network access. The final PDF/build logs and
the independent reproduction record document the actual delivered version;
different TeX versions can change pagination and PDF bytes.

The structural delivery validator can be run with:

    python3 code/validate_delivery.py

It uses Python's standard library and the Poppler pdftotext command. It does
not rerun the literature search or certify the mathematical arguments.

## Evidence and scope

The bibliography distinguishes an opened source from a fully read result.
Item-level verification and the research logs specify the actual reading
scope. An unresolved fragment is retained as such; a later thematic paper is
not treated as an exact solution. Dates of receipt, circulation and publication
are kept distinct where the available evidence supports them.

The input manuscript transcriptions, scan archive and third-party article PDFs
are not redistributed here. The supplied prior index, cumulative bibliography,
task brief and catalogue list are preserved as contextual regeneration inputs.
source_manifest.json records hashes of the six supplied attachments. Source
links and exact reading locators remain in the bibliography and research logs.
