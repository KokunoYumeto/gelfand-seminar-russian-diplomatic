# GY1978 — the Gelfand seminar, 1978–79

Open **GY1978_test.pdf** for the compiled critical companion and
**GY1978_report.md** for the inventory counts, research limits, provenance
migrations, checking methods and website recommendations.

The chapter contains all fourteen commissioned catalogue records and a
source-established, explicitly partial addition for Fuchs's 5 March 1979
lecture: **15 records, 216 items, 5 problem entries, 66 references and
105 corrections**. All 54 supplied scans are accounted for. The last two
belong to Kallosh's September 1979 lecture and are documented separately.

## Required source files

- `GY1978_talks.json`
- `GY1978_items.json`
- `GY1978_problems.json`
- `GY1978_overview.tex`
- `GY1978_development.tex`
- `GY1978_corrections.csv`
- `GY1978_references.bib`

`GY1978_chapter.tex` and `GY1978_test.tex` are generated by the supplied
`build_chapter.py`. The supplied style and format guide are included.
Supplementary JSON files record source coverage, historical aliases,
primary-area assignments and the out-of-year boundary inventory.

## Rebuild

With a standard TeX Live installation providing XeLaTeX and BibTeX:

```bash
python code/build_validate.py
```

This runs the required data builder and XeLaTeX–BibTeX–XeLaTeX–XeLaTeX
sequence. Complete output is retained in `code/build_logs/`. A local-only
format-cache fallback is available for installations whose package trees
exist but whose filename database and precompiled format are missing.
The helper never downloads packages or changes the system installation.

## Reproduce the mathematical checks

The checking scripts require Python, SymPy and mpmath. The versions used
are recorded in `code/environment.txt`.

```bash
python code/run_checks.py
python code/validate_data.py
```

Each calculation has a matching `*_output.txt`. The scripts distinguish
exact symbolic assertions from finite numerical corroboration. They do
not promote finite experiments to universal theorems. The chapter gives
the proofs and states their hypotheses.

`code/research_logs/` contains the per-area search records, reading limits,
scan inspection ledgers and independent mathematical reviews. Downloaded
literature PDFs and scan thumbnails were research intermediates and are
not redistributed here. The bibliography records opened URLs and the
one explicitly unverified publisher link separately from result-level
verification.

No precise class C or D problem survived the identification audit. The
development file contains completed critical checks of recorded claims,
with no claim of a new solution to an open problem.
