## Method limitations

The A–F scale combines chronology, authorship and present mathematical state. It does not by itself distinguish a theorem already submitted by another author from old exposition, nor a statement that is false literally but has an exact standard repair. Those facts must remain in the chronology, literal-correctness and reconstruction fields. An exact publication title is weaker than an exact theorem match: Vigneras is the clearest example here. The source log includes failed access attempts so an eventual reviewer can see why a verification level was downgraded.
