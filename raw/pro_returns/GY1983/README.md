# GY1983 source recovery

This archive preserves all requested textual deliverables, the complete 413-item chapter, corrections, references, research audits and executed mathematical checks. The compiled PDF is unavailable. Read GY1983_build_status.json and GY1983_report.md before treating this as a completed build.

With a full TeX Live installation, run `node GY1983_render.js`, then `xelatex -halt-on-error GY1983_test.tex`, `bibtex GY1983_test`, and XeLaTeX twice more. The renderer is a recovery replacement; it is not the supplied kit builder.

The original attachments and kit were lost during the environment failure. Source readings and uninspected scan ranges are explicitly qualified. No D classification is inferred from a failed search.
