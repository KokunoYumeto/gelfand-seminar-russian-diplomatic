## Rebuilding

Requirements are Python 3, XeLaTeX, BibTeX, the LaTeX packages loaded by the supplied style, and a Unicode text font with Cyrillic support. DejaVu Serif is suitable. The supplied builder and style are included unchanged, with comparison copies under `code/kit_original`.

The standard commands are:

```bash
python build_chapter.py GY1982
xelatex GY1982_test
bibtex GY1982_test
xelatex GY1982_test
xelatex GY1982_test
```

The checked wrapper also runs the semantic validation and can repeat the exact matrix calculation:

```bash
python code/rebuild.py --calculations
```

The optional calculation requires SymPy. On the minimal TeX installation used for this task, the wrapper generated a local XeLaTeX format from the installed distribution; it did not change system files. A complete TeX installation uses its existing format. `code/build_logs` records the commands, results, and final diagnostics.

To inspect the PDF geometry, install PyMuPDF and run:

```bash
python code/pdf_checks.py GY1982_test.pdf --report code/pdf_geometry.json
```

This geometry check supplements visual inspection; it does not certify mathematical correctness or replace reading rendered pages.

## Research and verification

`research` retains the three independently researched groups and the root author's development audit. Their JSON/CSV drafts document the assembly history; the principal files at the archive root incorporate the final editorial changes. The research folders contain source locators, opened URLs, access limitations, independent computational checks, and reviews. Full copies of later published papers and the original scan packet are not redistributed.

The following files make the integration reviewable:

- `code/input_manifest.json`: original attachment names, sizes, and SHA-256 values.
- `code/assembly_audit.json`: source order, bibliography-key reconciliation, and assembly decisions.
- `code/editorial_edits.json`: final mathematical typography and prose edits, with before/after text.
- `code/editorial_audit.json`: per-reference source checks and links from every false-as-written item to correction rows.
- `code/source_coverage.json`: item locators and coverage of the 89 pages belonging to this academic year.
- `code/validation_statistics.json` and `code/report_statistics.json`: derived counts and semantic checks.
- `code/haar_check.py`, its stdout, and `code/haar_check_results.json`: exact symbolic matrix-integral checks.
- `research/spring_integrable/development_review.md`: an independent character derivation and review of the local-limit theorem's hypotheses.
- `code/pdf_geometry.json` and `code/visual_review.json`: final PDF inspection.

The bibliography's `verified` label records a successfully opened source route. Reading a result, checking metadata, and using an explicitly indirect account are distinguished at item and source-audit level. No claim is made that every cited paper's complete proof was independently re-proved.

The mathematical development proves a local expansion in the exact notebook convention. It neither asserts novelty for the elementary coefficients nor supplies an all-coupling solution. The scalar case and all limiting operations are treated separately in the text.

The final scan P001115 starts Deligne's 5 September 1983 talk and belongs to the next academic year. Its presence in overlapping catalog page ranges is preserved in the metadata, but it supplies no mathematical occurrence in this chapter.
